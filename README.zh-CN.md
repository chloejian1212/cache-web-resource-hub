# CACHE Web Resource Hub

**将不断增长的资源集合，转化为已上线的主题化学习入口。**

[查看正式网站](https://carolinaadvocates.org/resources) · [教育与培训页面](https://carolinaadvocates.org/resources-et) · [English](README.md)

这是为 **Carolina Advocates for Climate, Health & Equity（CACHE）**开展的团队合作项目，涵盖用户研究、信息架构、内容设计和 Squarespace 网站制作。项目依托北卡罗来纳大学教堂山分校 INLS 779 实践课程开展。

最终资源中心已上线，通过主题入口、基础学习内容和可展开的资源列表，帮助不同背景的访问者选择阅读路径。本仓库提供研究与设计案例、上线截图及正式页面链接。

## 项目挑战

CACHE 的访问者有不同需求：临床工作者可能需要能直接使用的材料，学生希望了解一个新主题，另一些用户则需要更深入的资料。设计需要降低初次浏览的负担，同时保留完整资源集合的深度。

利益相关者讨论和用户研究共同支持了导航、资源组织、可信度和实际使用场景方面的设计工作。

**核心设计问题：如何帮助用户找到清楚的起点，并在需要时继续深入？**

上线主题页面采用的主要结构包括：

- 简短的主题介绍，说明当前内容范围。
- 明确的基础学习区域，提供精选入门资源及说明。
- 可展开的更多资源列表。部分主题按文章、网页和视频组织，教育培训页面使用网页资源列表。
- 相关主题链接，以及返回资源中心的入口。

本次已实际展开教育培训页的资源列表。个别导航链接仍有问题，具体记录在[上线页面核对说明](docs/LIVE_SITE.md)中。

## 从研究到设计，再到上线

| 研究或利益相关者输入 | 设计方向 | 正式页面上的体现 |
| --- | --- | --- |
| 用户对信息深度的需求不同。 | 将清楚的入门内容与进一步阅读分开。 | 基础学习内容位于前部，更多资源放在后续可展开列表中。 |
| 密集资源集合容易让下一步不明确。 | 通过主题帮助用户进入资源集合。 | 资源中心提供带图片和简短说明的主题入口。 |
| 不同资源格式适合不同任务。 | 让用户更容易按资源类型浏览。 | 部分主题页将文章、网页和视频分组呈现。 |
| 机构需要在项目结束后继续维护。 | 使用既有平台，并规划持续更新。 | 网站在客户平台上线，仓库提供建议维护流程。 |

这里呈现的是研究主题与可观察设计之间的联系，不代表每项设计都已测得效果提升。

## 成果与反思

项目形成了可以直接访问的正式资源网站。最清楚的可见成果，是从主题概览、基础学习到进一步阅读的分层路径。

这次工作让我更加关注用户连续作出的选择：先选择主题，再判断从哪里开始，最后继续深入。清楚的内容层级和持续维护，与初次页面设计同样重要。

在缺少可核验对比数据的情况下，文档没有宣称可用性评分、查找耗时、转化率或网站流量有所提升。本次网页核对确认了可见的上线内容，不等同于完整的无障碍审计或全部外部资源验证。

## 如何使用本仓库

直接在 GitHub 阅读 Markdown 文件即可，无需安装依赖或启动服务。可点击的动态预览位于 `assets/previews/`，补充截图位于 `assets/screenshots/`。Squarespace 网站及其后台配置在客户平台独立维护。

参与者原始记录、录音、联系方式、内部工作文件和原始分析数据未包含在仓库中。网页图片与第三方资源保留原有权利归属，见[团队致谢](CREDITS.md)。
